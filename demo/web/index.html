How it works

Every square of a QR code becomes one tile on the ground. Dark squares are planted: grass around the three corner markers and blossoms in the middle. Light squares are bare stone.

Tap the scene and the tree bows out while the camera rises overhead. From up there the plantings line up into a real QR code your phone can scan. Tap again to bring the tree back.

Type any link or text on the left to replant it. Season and bloom colour change the look, not the code.

Scanning tip: keep the whole square on screen. Error correction is set to "Q", so the code survives a few stray petals, and the API decodes every code before you see it.
