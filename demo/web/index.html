How the garden works

Every square of a QR code is one tile of this garden. Dark squares are planted: grass around the three corner markers and flower beds in the middle. Light squares are bare stone paths.

Tap the garden and the tree bows out while the camera rises overhead. From up there the plantings line up into a real QR code your phone can scan. Tap again to bring the tree back.

Type any link or text below the garden to replant it. Seasons and flower colours change the look, not the code.

Scanning tip: hold your phone so the whole square fits on screen. Error correction is set to "Q", so the code survives a few stray petals, and the API decodes every code before you see it.
